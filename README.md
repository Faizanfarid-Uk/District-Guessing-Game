# 🗺️ District Guessing Game

A Python-based GUI guessing game where players are challenged to name all districts from a predefined list. The game tracks correct guesses, avoids duplicates, and generates a report of missed districts when the player quits.

---

## 📌 Overview

The **District Guessing Game** is an interactive Python application designed to test users’ knowledge of district names. Players continue guessing until all districts are named or they type **`quit`** to exit. Once exited, the program automatically creates a file listing all the districts that were not guessed.

This project demonstrates practical usage of:
- Python GUI development
- CSV file handling
- Data validation
- File input/output operations

---

## 🎮 How It Works

1. The game prompts the user to enter district names.
2. Correct guesses are accepted and stored.
3. Duplicate entries are ignored.
4. Typing **`quit`** ends the game.
5. A file containing all missed districts is generated automatically.

---

## 🧰 Tech Stack

- **Language:** Python  
- **GUI Framework:** Tkinter  
- **Data Storage:** CSV  
- **File Handling:** Python File I/O
